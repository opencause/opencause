# Contributing to OpenCause

Thanks for your interest in contributing to OpenCause!

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a branch for your feature or fix
4. Make your changes
5. Submit a pull request

## Development Setup

See [README.md](README.md#development-setup) for setup instructions.

## Code Style

- Use consistent formatting (Prettier defaults)
- Keep commits focused and atomic
- Write clear commit messages

## Pull Requests

- Reference any related issues
- Describe what your PR does
- Keep PRs focused on a single change
- Ensure tests pass (when applicable)

## Reporting Issues

- Check if the issue already exists
- Provide clear reproduction steps
- Include relevant environment details

## Questions?

Open an issue or reach out on Discord (coming soon).
